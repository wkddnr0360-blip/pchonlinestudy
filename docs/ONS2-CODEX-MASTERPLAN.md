## 2. 인증·이용권
- Google·카카오 OAuth를 우선한다. 카카오 가입은 앱의 카카오 회원번호로 식별하며 이메일과 전화번호 동의를 요구하지 않는다. 자체 이메일 인증·비밀번호 재설정은 발신 설정이 있는 환경에서만 활성화한다. Better Auth와 D1으로 세션을 관리하며 계정 연결은 양쪽 재인증을 전제로 한다. 동일 이메일만으로 자동 병합하지 않는다. 비밀번호 해싱은 검증된 인증 라이브러리를 사용하고 무차별 대입·열거를 차단한다. CSRF·Origin, PKCE·state, OIDC 사용 시 nonce, HttpOnly Secure SameSite 쿠키와 세션 회수를 검증한다. 관리자는 서버 역할과 기존 인증 조건, MFA를 매번 확인한다.
- 확정 권한: 로그인한 무료 회원은 1단계(504) 학습·번호 지정·1단계 오답 및 무한의 탑 일반모드(1단계 100%, 최대 Silver 개인 성장 티어) 이용. 유효한 교재 구매 인증 이용권 회원은 1/2/3단계 전체 3,129문항·실전 모의고사·일반모드(1/2단계)·Gold까지 승급·Gold 이상에서 도전모드(2/3단계 50:50)·시즌 경쟁 랭킹·명예의 전당 이용. 무료 회원의 순위 조회/경쟁 랭킹 등재·Gold 이상·도전모드 금지. 로그인 전에는 소개/권리자가 허용한 샘플만. 기존 1단계 실전 모의고사도 잠금. '유료회원'은 교재 인증 이용권을 가진 회원; 사이트 결제 기능 없음.
- 교재 이용권 종료: 2027-03-15 00:00 KST exclusive (2027-03-14T15:00:00Z). 서버 UTC 판정, 요청별 확인, 만료·회수 후 인증 회원 전용 문제/정답·랭킹 접근 차단. 기본 1단계는 무료 유지로 제안(전체 서비스 종료 여부는 소유자 확정). 시즌 갱신과 만료/잠금 UX, 과거 랭크 보존.
- 신청: 로그인 → 네이버 카페 닉네임 + 교재 포스트잇 손글씨 + 임시 촬영용 난수(추가 제안) → 브라우저 JPEG 압축 및 비공개 D1 저장 → 관리자 수동 검토 → approved/rejected/resubmit → 사용자 귀속 코드 발급 → 입력 → entitlement. 카페 닉네임은 네이버 로그인/카페 회원 자격을 증명하지 않음. 코드 CSPRNG 128bit 이상, 서버 hash만 저장, 사용자/시즌/승인 요청 귀속, 발급 만료 제안 7일, 재발급시 이전 코드 폐기, 1회 원자적 사용/재전송 idempotency. 코드 화면 1회 표시, 안전한 전달, 로그 금지. 승인·권한 변경 audit. 사진 크기/형식 확인·EXIF 제거·비공개, 접근 기록·개인정보처리방침·탈퇴. 승인 사진은 승인 후 7일이 지나면 자동 파기하고 승인·티켓·이용권 기록은 보존한다. 반려·재제출 사진의 보관 기간은 환경별로 설정한다. 원본 사진을 MCP 응답에 기본 포함하지 않음; 관리자 직접 조회 또는 명시적 제한 조회.
- 기존 브라우저 진도 마이그레이션은 사용자가 선택, 계정 격리, 임의 merge 금지. 서버 동기화는 stable question ID와 attempt events만. 민감 본문/해설/토큰은 IndexedDB, SW, backup, CDN, 정적 dist에 금지. 모의고사도 ID+사용자 답안만 저장. /api private,no-store; 과거 SW cache 이름 정리 및 안전한 업데이트/rollback 경로. 로그인 실패/네트워크 중단은 fail closed. 질문은 필요한 1개씩, 채점 서버, 해설은 제출 후; 시험/랭크 해설은 종료 이후, 복습에는 별도 권한 검사.

## 4. 무한의 탑: 일반모드와 도전모드
현행 src/challenge는 5정답/1스테이지, 하트3, local 점수, stage2/3 가변 비율, 좌우 캐릭터 이동. 유지할 리소스와 로직을 구분하고 ranked 신규 서비스로 전환.
- 두 모드 공통: 1정답=1층 상승, 서버에서만 정답 및 진행 판정. 오답 시 층 이동 금지. 스테이지 번호와 교재 단계(1/2/3)는 별개. 탑은 시각적으로 무한하되 유한 문제 풀과 중복 정책 명시.
- 일반모드: 무료 회원은 교재 1단계 100%, Bronze/Silver 개인 성장 티어만 가능; 유효한 구매 인증 회원은 1/2단계만(50:50 초기 제안, 설정 가능), Bronze/Silver/Gold 가능. 어느 경우도 3단계 출제 금지. 시간제한/하트 소모 없음, 오답 즉시 해설 후 다시 풀기 또는 다른 문제. 시즌 내 최초 정답을 기록한 고유 문항 수로 승급; Bronze는 유효한 첫 일반모드 제출 시, Silver 50개, Gold 200개(제안). 무료 회원은 Silver 이후에도 자유롭게 학습하되 Gold 승급/도전모드/경쟁 순위 금지. 승급 점수 중복 적립 금지. 일반모드 층과 승급 진척을 별도 표시. 이번 시즌 무료→인증 전환 시 서버가 기존 유효 고유 정답 기록을 재사용하고, 새 entitlement 확인 후 Gold 가능 여부 재계산(초기 제안, 별도 중복 적립 없음). 권한 만료/회수 시 향후 일반모드 문제를 1단계로 제한하고 현재 이용 가능한 개인 티어는 최대 Silver로 표시, 역사적 기록 보존. 이용권/Gold seed 검사 후 도전모드 해금. 모든 개인 성장 기록은 시즌마다 4.1에 따라 리셋.
- 도전모드: 전범위 동일 규칙, 교재 2단계 50%, 3단계 50%. 2문항 블록마다 2/3 각 1개, 순서 무작위 → 완료 블록 정확히 50:50, 홀수 prefix 차이 최대 1. 문항 중복 금지(한 run 및 가능한 최근 run 간 회피), 공급 부족 시 세션 종료/기록 정책, 난이도/목차 비중 및 공정한 출제는 별도 통계 확인. 한 문제 정답당 1층, 오답/시간 초과 하트 -1, 3하트 소진 종료, 층 유지하고 새 문제, 해설은 종료 후. 초기 타이머는 읽기 길이 반영한 서버 기준(권장 30–60초), 빠른 답 자체에 점수 가산 없음. 최종 확정 전 실제 문항 길이/유저 데이터로 튜닝. 유효 도전 기록은 서버 채점 및 세션 종료(중단 처리 일관), 동일 시즌/룰/콘텐츠 버전으로 산정. 최고 클리어층 우선, 동점은 해당 기록 최초 달성 시각 오름차순, 마지막 안정 ID. 초기 실력 하한: P 20층, D 40층(제안). 최고점은 룰이 같을 때만 비교. 1인 1 active ranked run, turn nonce + deadline + sequence + idempotency. 중복/위조/재전송/조작된 시간/다른 계정 요청은 거절. refresh/network drop은 기존 turn 복구, 같은 점수 이중 적립 불가; 서버의 명시적인 일시 장애 처리 정책. score=server derived, client score·answer key·seed 미노출.
- 상대 티어: N=현재 랭킹 시즌의 유효한 교재 인증 이용권을 보유한 Bronze 이상 정상 계정 고유 인원(일반모드 유효 제출 ≥1 또는 직전 시즌 P/D로 Gold seed, 언랭 및 무료 회원 제외). 무료 회원은 개인 Bronze/Silver 진행만 제공하고 경쟁 순위·분모에서 제외하는 기본 해석. Gold seed는 이번 시즌 첫 플레이 전에도 Gold이므로 분모에 포함하는 기본 제안. 새 시즌 도전 최고 기록 없으면 P/D 후보에서 제외. Diamond cap=floor(N*0.01), 상위 티어 합계 cap=floor(N*0.10); Platinum은 Diamond 제외 상위 10% 범위. N<100 D 없음; N<10 P 없음. - 예시 N=300: D 최대3, P+D 최대30(P 최대27 if D3), N=1000 D10 P+D100. 소규모/동점/정지/유효 기록 부족/시즌 종료/중복 제출 테스트.
- 권한 게이트: 일반모드의 start/turn/answer/resume은 로그인과 현재 이용권에 맞는 문제 풀 및 승급 상한을 요청별 서버 검증. 도전모드, 경쟁 rank/me, leaderboard, season archive, hall of fame, 공유용 경쟁 기록 생성은 유효한 교재 인증 이용권을 별도로 검증. 일반모드에서도 유효한 기존 turn이 권한 변경으로 잠긴 문제라면 취소하고 허용 풀로 다시 발급, 답안·진척 중복 없음. 무료 응답에 순위·타 회원 닉네임/기록·2/3단계 원문 미포함. 관리자 웹/MCP는 별도의 admin role/scope 검증. 개인 정보 열람·삭제는 별도 계정 절차로 제공. 무료 가입/실버 상한/직접 URL/API/위조 클라이언트/권한 전환/회수 통합 테스트 필수.
- 랭킹 화면: 내 티어+개인 최고층+현재 순위/참여자 수/상위 %, 다음 티어 목표, Gold 잠금 안내, 랭킹 상위/내 주변, 익명화한 공개 닉네임(동의), 티어 설명, 규칙 버전 및 마지막 갱신, 신고/부정 기록 처리. 순위를 강제로 노출하지 말고 공개 선택; 점수는 전체 유효 모집단으로 산정. 훈련/랭크 구분, 타이머 부담 최소화, 하루 목표/종료를 존중하는 UX.

- UX: 게임 상단은 현재층, 남은 하트(도전), 내 티어, 타이머, sound, 종료. 장면 아래 읽기 편한 문제와 OX 버튼, canvas가 입력/스크롤 가리지 않음. 정답/오답 상태 서버 응답을 기다리고 중복 탭 방지. 결과는 최고층·정답/오답·등급·랭킹·오답 복습·종료. 사운드/캐릭터는 정답률 또는 공부 시간에 악영향 없는지 검증.
