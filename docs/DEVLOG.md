# 개발 기록

## 2026-11-23 · 유료 이용권 기능 (작업 브랜치, 미배포)

- 1단계 무료, 2·3단계 및 실전 모의고사/해당 오답 복습 유료 정책으로 라우트 게이트 구현.
- Cloudflare Workers D1 계정·서버 세션·코드 1회 등록·관리자 코드 발급 API 및 비공개 R2 문제 전송 스캐폴드 작성.
- 앱에서 API 환경변수 지정 시에만 잠금이 활성화되도록 작업 브랜치에서 단계적 배포 처리. 운영 중인 GitHub Pages 배포는 변경하지 않음.
- 기존 공개 GitHub 저장소와 GitHub Pages/서비스 워커 캐시에 유료 문제 원문이 있어, 비공개 이전·과거 공개 이력 대응 및 저작권 확인 없이는 출시 불가.
- 실서비스 배포/PG/이메일 인증/비밀번호 재설정과 유료 E2E 검증은 미완료. 자세한 내용은 cloudflare/README.md.

## 2026-11-22 · Canary 1.1.0

- 앱 이름을 박철한 온스로 바꿨다. 홈에 무한회독과 첫 방문 버전 안내를 표시하고, 파비콘과 iOS 홈 화면용 아이콘, PWA 아이콘에는 새 철한쌤 도트 초상화를 적용했다. 설치 앱 ID와 학습 DB 이름을 유지했다.
- 단계별 카드의 말투를 바꾸고, 캐릭터를 터치하면 웃음·활짝 응원·불꽃 응원으로 움직이게 했다. 시스템에서 모션 줄이기를 사용하면 움직임과 파티클을 줄인다.
- 오답노트는 교재 목차로 묶고 장 안에서는 교재 번호순으로 정렬한다. 모의고사 오답은 정답 보기의 교재 번호를 기준으로 배치한다.
- 터치 효과음은 Web Audio로 직접 합성한다. 재미 모드는 소프트 벨·픽셀 콤보·기기 한국어 응원 음성으로 구성한다. Review08 클립의 공개 재배포 조건을 확인하지 못해 해당 녹음은 사용하지 않았다.
- 자동 백업은 앱을 사용하는 동안 선택한 폴더나 기기 보관함에 기록한다. 보관함은 최근 3개를 유지하고 백업 대상 설정과 폴더 핸들을 내보내지 않는다. 기존 백업을 계속 읽을 수 있다.
- 원본 HWPX 재추출 검증, 단위 테스트 6개, Chromium 데스크톱·모바일 테스트 14개를 통과했다. iPhone 크기의 WebKit에서 이름 메타데이터, 캐릭터 터치, 기기 보관함 자동 저장도 확인했다.
- 메인 제목을 ‘헌법의 핵심은 무한회독’으로 조정했다. 모바일에서 단어 단위로 줄을 바꾸도록 했다.

## 2026-11-22 · PWA 업데이트

- GitHub Pages의 기본 캐시 헤더를 사용하는 환경에서 앱 코드가 별도의 배포 표식을 캐시 없이 확인한다. 새 배포의 서비스 워커 파일은 고유 경로에서 받아, 해당 버전이 설치된 뒤에만 업데이트를 알린다.
- 앱을 열거나 다시 활성화하거나 인터넷에 재접속할 때 확인한다. 온라인에서 앱을 보고 있으면 3분 간격으로 다시 확인한다.
- 학습 화면과 진행 중인 모의고사에서는 적용을 미룬다. 모의고사가 다른 탭에 있어도 감지하며, 업데이트를 적용하는 탭만 다시 연다.
- 최근 앱 화면 캐시 3개를 유지해 이전 탭이 자신의 파일을 계속 읽도록 했다. 교재 캐시와 IndexedDB 학습 기록에는 별도 저장소를 사용한다. 앞으로 이전 코드를 배포할 때도 새로 빌드하면 새 배포로 감지된다.
- 두 개의 실제 빌드를 같은 주소에 배포하는 브라우저 테스트를 추가했다. 온라인 복귀 감지, 모의고사 대기, 선택한 탭의 업데이트, 진도 보존과 새 버전의 오프라인 풀이를 검증한다.
- 기존 고정 서비스 워커 주소에서 새 방식으로 전환되는 동안 이미 열려 있는 화면은 그대로 동작한다. 이전 배포를 열어 답안을 저장한 뒤 새 서비스 워커로 바뀌고 앱을 다시 열어 진도가 유지되는 것을 확인했다. iPhone 크기의 WebKit에서 버전별 서비스 워커 설치와 오프라인 재실행도 확인했다.
