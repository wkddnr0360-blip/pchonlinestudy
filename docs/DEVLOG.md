# 개발 기록

## 2026-11-22 · v1

- 첨부 HWPX의 교재 번호는 1–3,129번이다. 1단계 504문항, 2단계 1,355문항, 3단계 1,270문항이다.
- HWPX의 좌우 평행 단이 서로 다른 XML 구간에 저장된다. 번호 스타일과 본문 제목으로 문항의 편·장·절을 찾아 해설 표시 순서와 연결했다. 585번 표, 1,892번의 추가 문단, 정오 표기 변형을 보존했다.
- 2026년 2차 경찰채용 기출의 20문항 구성과 헌법총론 4문항·기본권론 16문항 배분을 참고했다. 지문과 정오 값은 교재만 사용한다.
- Vite와 React로 정적 앱을 구성하고, Dexie로 학습 기록을 저장한다. GitHub Pages 프로젝트 경로에서 동작하도록 해시 라우팅과 빌드 경로를 설정했다.
- 도트 캐릭터에 대기, 단계 진입, 정답 축하, 오답 격려 모션을 적용했다. 시스템의 모션 줄이기 설정을 지원한다.
- 원본 HWPX에서 재생성한 27개 장 파일과 목차가 앱 데이터와 바이트 단위로 일치했다. 3,129개 문제·해설의 세로 배치도 대조했다.
- 단위 테스트 4개와 Chromium 데스크톱·모바일 브라우저 테스트 6개를 통과했다. 모바일 메뉴, 오프라인 이어 풀기, 시험 만료와 백업 복원을 포함한다.
- 공개 배포 저장소는 `wkddnr0360-blip/pchonlinestudy`다.
- [GitHub Pages](https://wkddnr0360-blip.github.io/pchonlinestudy/)에 첫 버전을 배포했다. 공개 환경에서 홈, 1단계 목차, 교재 1번과 기출 출처 표시를 확인했다. [GitHub Actions 배포 실행 기록](https://github.com/wkddnr0360-blip/pchonlinestudy/actions/runs/45036607800)
- iPhone 크기의 WebKit에서 교재 풀이, 새로고침 후 기록 유지와 서비스 워커 등록을 확인했다. 실물 iPhone에서 홈 화면에 추가하는 단계는 직접 확인하지 못했다.

## 2026-11-22 · Canary 1.1.0

- 앱 이름을 박철한 온스로 바꿨다. 홈에 무한회독과 첫 방문 버전 안내를 표시하고, 파비콘과 iOS 홈 화면용 아이콘, PWA 아이콘에는 새 철한쌤 도트 초상화를 적용했다. 설치 앱 ID와 학습 DB 이름을 유지했다.
- 단계별 카드의 말투를 바꾸고, 캐릭터를 터치하면 웃음·활짝 응원·불꽃 응원으로 움직이게 했다. 시스템에서 모션 줄이기를 사용하면 움직임과 파티클을 줄인다.
- 오답노트는 교재 목차로 묶고 장 안에서는 교재 번호순으로 정렬한다. 모의고사 오답은 정답 보기의 교재 번호를 기준으로 배치한다.
- 터치 효과음은 Web Audio로 직접 합성한다. 재미 모드는 소프트 벨·픽셀 콤보·기기 한국어 응원 음성으로 구성한다. Review08 클립의 공개 재배포 조건을 확인하지 못해 해당 녹음은 사용하지 않았다.
- 자동 백업은 앱을 사용하는 동안 선택한 폴더나 기기 보관함에 기록한다. 보관함은 최근 3개를 유지하고 백업 대상 설정과 폴더 핸들을 내보내지 않는다. 기존 백업을 계속 읽을 수 있다.
- 원본 HWPX 재추출 검증, 단위 테스트 6개, Chromium 데스크톱·모바일 테스트 14개를 통과했다. iPhone 크기의 WebKit에서 이름 메타데이터, 캐릭터 터치, 기기 보관함 자동 저장도 확인했다.
- 메인 제목을 ‘헌법의 핵심은 무한회독’으로 조정했다. 모바일에서 단어 단위로 줄을 바꾸도록 했다.
