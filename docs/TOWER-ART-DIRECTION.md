# 무한의 탑 — 철한쌤 원본 기반 아트 제작 가이드

상태: 디자인/납품 기준. 실제 새 이미지, 스프라이트, 엔진, 애니메이션은 아직 제작되지 않음. 2026-11-25 실제 GitHub 원본 확인.

## A. Canonical source of truth
기존 박철한 온스 공개 페이지(pch.oxstudy.kro.kr)에서 쓰이는 저장소 리소스를 기준으로 한다. 실제 사이트의 캐시/배포 버전은 별도 확인해야 한다.
- `public/characters/teacher.webp` — blob d0b9f5b2f6000c36c2cc9af158ccc5784b1f3775, 3개의 기본 자세가 가로로 배치. 캐주얼 네이비 가디건/녹색 책/밝은 바지, 보랏빛 재킷/펜/노란 책, 짙은 정장/저울 문양 법전.
- `public/characters/teacher-reactions.webp` — blob 5e51615ebb4d047199c3151d98e67aa72b2534c5, 웃는 얼굴/응원 자세 3종.
- `public/challenge/archive-scenes.webp` — blob 24d84f40e2e5e4baff3a8a2032a31c984aa0c55c, 햇살과 전통 장식 서재, 보라빛 원형 서재, 별자리 천문 서재.
- 기존 3단계 캐릭터/학습 UI는 삭제하거나 교체하지 않는다. 위 원본은 읽기 전용 레퍼런스로 유지. 새 탑용 아트를 별도 경로에서 관리.
- 필수 정체성: 옆으로 빗어 넘긴 볼륨 있는 검은 머리, 검은 둥근 안경, 둥근 치비 얼굴/눈썹·눈·미소, 기존 머리-몸 비례, 책/펜/법전, 친근한 강사 이미지. 단순 8비트 블록 얼굴이나 임의의 다른 인물 캐릭터 금지. 캐릭터를 모자/투구/과한 갑옷으로 가리지 않는다.
- 그림체 목표: 세밀한 32비트 JRPG풍 픽셀 일러스트. 유사한 머리카락 명암·피부 팔레트·실루엣, 픽셀 단위의 정리된 윤곽/질감. AI 초안을 그대로 자르거나 일반 이미지를 nearest-neighbor로 축소한 것만으로 완성 판정하지 않는다. 사용자/권리자의 사용 및 변형 허락과 아트 승인 필요.

## B. Five-tier design bible
| Tier | 기존 이미지 계승 | 강화된 캐릭터 디테일 | 배경·상승 연출 |
|---|---|---|---|
| Bronze | 원본 1단계 | 네이비 가디건, 초록 책, 구리 책갈피 | 햇살 비치는 한옥풍 서재, 목재 계단, 먼지/꽃잎 |
| Silver | 원본 2단계 | 보랏빛 재킷, 펜, 은빛 책장식 | 달빛 기록관, 은빛 난간, 등불/은빛 잔광 |
| Gold | 원본 3단계 | 검은 정장, 황금 저울 문양 법전, 절제된 금색 액센트 | 황금 법전의 전당, 층별 금빛 조명·문 열림 |
| Platinum | 원본 3단계의 얼굴과 비례 | 고급 청록빛 네이비 정장, 백금/청록 법전, 작은 백금 브로치 | 별빛 성채·청록 기둥, 별가루와 상향 광선 |
| Diamond | 원본 3단계의 얼굴과 비례 | 깊은 남색 정장, 다이아 결정 문양과 은빛 법전, 미세한 별빛 오라 | 하늘의 헌법 전당, 수정창/별자리·구름·푸른 빛 |
- 티어 명칭은 서체/아이콘과 함께 전달; 캐릭터 얼굴을 가리는 왕관·무기·과도한 갑옷/효과는 피한다.
- 등급별 같은 자세의 전신/얼굴 비교 시트 1장, 원본과 동일 인물로 인식되는지 리뷰 후 모션 제작.
- 랭킹용 256px 이상의 상세 초상화(최종 UI에서 48~96px로 표시), 작게 봐도 식별되는 별도 티어 엠블럼. 기존 게임의 고유 로고 및 상표를 복제하지 않는다.
- 랭킹 경쟁 시즌이 바뀌어도 tierId/캐릭터 key는 고정, 이름/팔레트/배경 리소스는 manifest에서 교체.

## C. Sprite and animation deliverables
- 편집 가능한 Pixelorama 프로젝트, lossless PNG atlas + frame JSON + anchor/animation manifest. 128×160 논리 셀(초기 제안, 기기 비교로 확정), 발바닥 anchor 고정, 일관된 조명/팔레트, 투명 배경 및 불필요한 검은 테두리/halo 제거. Atlas padding 및 픽셀 bleed 방지.
- Tier별 idle 6~8 frames, 걷기 8, 계단 오르기 8~12, 정답 기쁨 8, 오답 격려 4~6, 승급 10~14 frames를 제안. 먼저 1종의 완성된 계단 루프를 검수하고 나머지 티어로 확장. 캐릭터 얼굴이 프레임마다 변형되면 불합격.
- 정답 확인 → 기존 문제의 채점 결과 즉시 표시 → 철한쌤이 계단 한 층 올라감(0.45~0.75초 권장, animation skip/fast-forward 가능) → 카메라가 위로 이동하고 새 층이 등장. 틀림 → 그 층에서 짧은 격려 모션. 도전모드는 하트 변화. 다음 문제의 타이머는 서버 정책으로 시작, 렌더링 지연으로 수험생 불이익 금지. 10층 체크포인트/50층 새로운 풍경은 장식이며 추가 정답을 요구하지 않음.
- 승급 모션 1~1.5초 권장: 현재 캐릭터 실루엣 유지, 법전/정장/티어 엠블럼 전환, 짧은 픽셀 파티클. 반복 학습에서 강제 대기·과도한 번쩍임·소리 기본 활성 금지. 모션 축소/끄기 즉시 적용.
- 장면 초안 640×360 논리 해상도, 층 반복 가능한 16 또는 32px 기반 타일, 전경/중경/원경 3층, 창문·조명·난간·책장·계단·문/별자리 장식. 기존 배경의 섬세한 한국풍 책장, 단청, 황금/보라/별빛 색감을 계승. 위로 올라가는 공간을 시각적으로 연결하고 같은 장면 반복만 보이지 않도록 변주. Tiled에서 맵 편집 및 재사용.
- Phaser에서 pixelArt/roundPixels/nearest-neighbor 계열 옵션을 현재 설치 버전 공식 문서에 맞춰 검증. 정수 스케일/픽셀 정렬, 필요 시 letterbox; 배경과 캐릭터의 서로 다른 해상도 선택은 실제 화면으로 검증. Canvas 영역 밖의 질문/해설/OX 버튼은 React DOM 유지.

## D. Maintainability and release checks
- `src/game/renderer`, `src/game/scenes`, `src/game/assets` 등 기존 마스터 명세 경계 준수. `src/game/assets/tower-manifest.ts` 또는 동등한 versioned manifest로 tier → portrait/atlas/animation/scene 대응. 화면 곳곳에서 파일명을 하드코딩하지 않는다. 기존 src/ui/Teacher.tsx와 구분해 기존 학습 홈에 변경 전파 방지.
- Art source는 private repo/권한 있는 storage, production은 승인된 최적화 atlas와 배경만 배포. 오픈소스 라이선스와 상업/비상업 사용 조건, 원본 캐릭터 사용 허락, credits 기록.
- Lazy-load Phaser/아트, atlas 및 씬 단위 캐싱, 모바일 initial game payload 목표 2MB 이하(압축 전후 측정 및 필요시 예외 승인), 작은 viewport/저사양 기기용 정적 대안. 60fps 목표, 대표 모바일 실측/메모리/다운로드 수치로 검증. 타이머/점수/권한은 서버, 렌더러는 입력 이벤트를 시각화만 한다.
- 실제 기존 캐릭터와 신규 5티어 정면/3분의2 각도 및 스프라이트 비교, 발 정렬, 애니메이션 루프, 흰/검은 배경 alpha 경계, 폰 화면 확대/가로/세로에서 판독성 확인. 실물 iOS/Android 캡처나 영상, atlas 규격 테스트, Playwright visual snapshot, reduced motion 검증을 제출한다.
- 출시 게이트: 사용자에게 원본 대비 5개 티어 정지 시트 및 실제 올라가기 동작 샘플을 먼저 승인받고, 이후 전체 프레임/배경을 제작. 샘플/초안/완성/배포를 구분하여 DEVLOG에 기록. 현재는 기준 명세만 반영함.
